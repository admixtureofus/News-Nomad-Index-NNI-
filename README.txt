뉴스 나침반(News Compass) — 대시보드 서비스 구현
NNI 기반 소비자 진단 · 언론사 배포 전략 서비스 프로토타입
================================================================

■ 개요
--------
본 산출물은 「NNI_추가산출물」에서 도출한 뉴스 유목민 지수(NNI)와
5개 군집 분류 결과를, 실제 서비스 형태로 구현한 웹 프로토타입입니다.
하나의 NNI 진단 엔진 위에 두 개의 서비스를 얹은 순환형 플랫폼으로,
보고서 5장(서비스/정책 제안)에 대응합니다.

  - 뉴스 닥터 (B2C) : 개인의 뉴스 소비 패턴 진단 + 원문 접점 처방
  - 배포 엔진 (B2B) : 같은 진단을 뒤집어 언론사에 이탈 독자 재접근 전략 제공


■ 폴더 구성
--------
뉴스나침반_대시보드_서비스구현/
├── README.txt                  (본 파일)
├── 뉴스나침반_랜딩_dc.html       (★ 진입점 — 랜딩 페이지)
├── 뉴스나침반_dc.html           (진단 대시보드 본체)
└── support.js                   (dc.html 렌더링 로직 — 필수 의존 파일)

  ※ 세 파일은 반드시 같은 폴더에 있어야 링크·스크립트가 정상 작동합니다.


■ 실행 방법
--------
1. 진입점: 뉴스나침반_랜딩_dc.html 을 브라우저로 엽니다.

2. 로컬에서 support.js·웹폰트 로드가 제한될 경우, 로컬 서버 실행을 권장합니다.

     # 파일이 있는 폴더에서
     python -m http.server 8000
     # 브라우저에서 http://localhost:8000/뉴스나침반_랜딩_dc.html 접속

3. 필요 환경: 최신 웹 브라우저(Chrome/Edge/Safari). 별도 설치 불필요.


■ 데이터 관련
--------
화면에 표시되는 수치는 서비스 컨셉 시연을 위한 예시 데이터입니다.
실제 지표 산출·군집 분류·검증 과정은 아래를 참조하십시오.

  - 분석 코드 : 「NNI_추가산출물」 폴더
  - 방법론·결과 : 제출 보고서 3~4장

  - 대시보드     → 보고서 5.3 뉴스 닥터 / 5.4 배포 엔진
