뉴스 유목민 지수(News Nomad Index, NNI) 분석 산출물
2025 언론수용자조사 기반 뉴스 소비 패턴 분석
================================================================

■ 개요
--------
본 산출물은 2025년 언론수용자조사(6,000명, 설계가중치 WT 적용
확률표본)를 활용하여, 개별 응답자가 원 저널리즘 소스로부터 얼마나
이탈했는지를 측정하는 복합 지표 "뉴스 유목민 지수(NNI)"를 산출하고,
이를 기반으로 뉴스 소비자 유형을 5개 군집으로 분류한 결과물입니다.


■ 폴더 구성
--------
NNI_추가산출물/
├── README.txt                      (본 파일)
├── 뉴스유목민지수_NNI_최종정리.ipynb  (★ 메인 노트북 )
├── code_detail/                     (상세 과정 — 필요시에만 참고)
│   ├── 01_전처리.ipynb
│   ├── 02_NNI산출.ipynb
│   └── 03_군집분석.ipynb
├── data_info/
│   └── 변수정의_tier매핑표.xlsx       (채널 tier 분류 기준: T0/T1/T2)
└── results/
    ├── 5군집_전체프로파일.xlsx        (군집별 평균 프로파일, 비중 등)
  

■ 실행 방법
--------
1. 뉴스유목민지수_NNI_최종정리.ipynb를 먼저 열람 (전체 분석 흐름 및
   핵심 결과 확인)
2. 세부 처리 과정이 궁금한 경우 code_detail/ 내 01→02→03 순서로 참고
3. 필요 패키지: pandas, numpy, scikit-learn, scipy, statsmodels,
   matplotlib, seaborn
4. 원자료는 파일 상단 DATA_PATH 변수를 환경에 맞게 수정 후 실행
