# 뉴스 유목민 지수(NNI)
### 복합지수 설계와 군집분석을 통한 뉴스 소비 패턴 분석

## 1. 프로젝트 개요

**뉴스 유목민 지수(News Nomad Index, NNI)** 는 다양한 뉴스 채널을 이용하는 양상을 하나의 지표로 요약하기 위해 설계한 복합지수입니다.

2025년 미디어 이용자 조사 데이터를 활용하여 뉴스 채널별 이용 빈도와 채널 간 소비 분포를 분석하고, 정보 엔트로피와 채널 티어 기반 가중 지표를 결합해 뉴스 소비 패턴을 측정했습니다. 이후 외부 변수와의 관계를 통해 지수의 타당성을 검토하고, K-means 군집분석으로 뉴스 소비자 유형을 탐색했습니다.

### 주요 분석 질문

- 뉴스 소비의 다양성과 채널별 이용 양상을 하나의 지표로 어떻게 측정할 수 있을까?
- NNI의 구성 요소는 서로 구별되는 뉴스 소비 특성을 반영하는가?
- 뉴스 채널 이용 패턴을 바탕으로 소비자 집단을 의미 있게 구분할 수 있을까?

## 2. 주요 분석 결과

| 분석 항목 | 결과 |
|---|---:|
| 전체 조사 응답자 | 6,000명 |
| 기준 주간 뉴스 채널 이용자 | 5,702명 |
| 기준 주간 뉴스 채널 미이용자 | 298명 (5.0%) |
| PCA 제1주성분 설명분산 비율 | 82.9% |
| NNI 구성 요소 간 상관계수 | \(r = 0.658\) |
| 최적 군집 수 | 5개 |
| 선택된 군집 설정의 실루엣 계수 | 0.5535 |

※ 실루엣 계수 0.5535는 군집 간 어느 정도의 분리도가 있음을 보여주지만, 집단이 매우 명확하게 구분된다고 단정할 수 있는 수준은 아닙니다.

## 3. 데이터 및 전처리

### 데이터 개요

- **데이터:** 2025년 미디어 이용자 조사
- **응답자 수:** 6,000명
- **설문 문항 수:** 223개
- **분석 단위:** 개인별 뉴스 채널 이용 패턴

### 뉴스 채널 티어 분류

뉴스 채널을 원천 정보와의 접근성 및 소비 경로를 기준으로 세 개의 티어로 분류했습니다.

| 티어 | 채널 유형 |
|---|---|
| Tier 0 | 신문, TV, 라디오, 잡지 |
| Tier 1 | 포털, 팟캐스트 |
| Tier 2 | 메신저, SNS, 동영상 플랫폼, 숏폼, 생성형 AI |

일반적인 플랫폼 이용 여부가 아니라 뉴스·시사 콘텐츠 관련 문항을 중심으로 채널별 이용 빈도를 구성했으며, 해당하는 경우 평일과 주말의 이용 정보를 함께 반영했습니다.

또한 설문 문항의 스크리닝 조건과 건너뛰기 로직을 확인한 뒤 결측값을 처리했습니다. 기준 주간 뉴스 채널 이용 기록이 없는 298명은 분석 과정에서 무조건 제외하지 않고 별도 집단으로 관리했습니다.

## 4. 분석 방법

### 4.1. 복합지수 설계

NNI는 두 가지 구성 요소를 결합하여 뉴스 소비 패턴을 요약합니다.

**① 정규화 Shannon 엔트로피 (\(H_{\mathrm{norm}}\))**

뉴스 채널 이용이 여러 채널에 얼마나 분산되어 있는지를 측정합니다. 값이 높을수록 특정 채널에 집중되기보다 다양한 채널을 이용하는 경향을 나타냅니다.

**② 티어 가중 편차 지표 (\(D_{\mathrm{weighted}}\))**

채널별 이용 빈도와 채널 티어를 반영해 뉴스 소비 양상을 요약합니다.

두 구성 요소의 상관계수는 \(r = 0.658\)이었으며, PCA 분석에서 제1주성분은 전체 분산의 82.9%를 설명했습니다. 최종 NNI 산출에서는 두 구성 요소에 동일한 가중치(\(\alpha = \beta = 0.5\))를 적용했습니다.

이를 통해 뉴스 소비의 다양성과 채널 티어에 따른 이용 양상을 하나의 지표로 요약하고자 했습니다.

### 4.2. 구성 타당성 검토

지수가 의도한 뉴스 소비 특성을 반영하는지 살펴보기 위해 지수 산출에 직접 사용하지 않은 외부 변수와의 관계를 분석했습니다.

- 뉴스 전반에 대한 신뢰
- 언론사 인지도
- 뉴스 유료 이용 의향
- 연령

분석 결과, 예상한 방향의 관계가 모든 변수에서 확인되지는 않았습니다. 특히 뉴스 신뢰와의 관계는 통계적으로 유의하지 않았으며, 언론사 인지도와의 관계에서는 예상과 다른 방향이 나타나 티어 분류 기준을 재검토할 필요가 있었습니다.

따라서 모든 가설이 검증되었다고 해석하기보다는, 지수의 측정 타당성을 추가로 점검해야 하는 결과로 해석했습니다.

### 4.3. 군집분석 및 특성 공학

뉴스 채널 11개의 개별 이용 빈도를 그대로 군집분석에 투입하는 대신, 티어별 이용 빈도 세 개로 집계해 분석 차원을 줄였습니다.

이후 이용 빈도 변수의 편향과 변수 간 스케일 차이를 고려해 여러 전처리 및 군집 설정을 비교했습니다.

분석 과정은 다음과 같습니다.

1. 티어별 이용 빈도 변수 구성
2. `log1p` 변환을 통한 편향 완화
3. 표준화를 통한 변수 스케일 조정
4. K-means 군집분석
5. 실루엣 계수, Calinski–Harabasz 지수, Davies–Bouldin 지수를 활용한 군집 설정 비교

초기 설정에서 약 0.42~0.43 수준이었던 실루엣 계수는 로그 변환과 표준화를 적용한 설정에서 **0.5535**로 개선되었습니다. 여러 평가 지표를 비교한 결과, 5개 군집을 선택했습니다.

이용 빈도가 낮은 채널을 제외한 경우 실루엣 계수는 0.5535에서 0.5598로 소폭 상승했습니다. 개선 폭이 크지 않아 희소 채널을 유지하는 방향을 택했습니다. 또한 여러 랜덤 시드에 대한 ARI가 1.0으로 보고되어, 해당 설정에서 군집 결과의 안정성을 확인했습니다.

## 5. 핵심 인사이트

### 뉴스 소비 다양성과 이용량은 구분해서 해석해야 한다

정규화 엔트로피와 전체 뉴스 채널 이용 빈도의 상관계수는 \(r = 0.824\)였습니다. 그러나 채널 수를 통제한 뒤에는 상관계수가 \(r = 0.142\)로 낮아졌습니다.

반대로 전체 이용 빈도를 통제한 상태에서 채널 수와의 상관계수는 \(r = 0.837\)로 나타났습니다.

이는 엔트로피 지표가 단순한 이용량보다는 이용 채널의 범위와 더 밀접하게 연결될 가능성을 시사합니다. 다만 이러한 결과만으로 엔트로피가 뉴스 소비 다양성만을 완전히 독립적으로 측정한다고 단정할 수는 없습니다.

### 군집화에서는 전처리 방법이 중요하다

이용 빈도 변수는 분포가 한쪽으로 치우쳐 있었으며, 특히 Tier 2 변수의 왜도가 높았습니다. 이에 로그 변환과 표준화를 적용해 거리 기반 군집분석에서 발생할 수 있는 변수 분포의 영향을 완화했습니다.

그 결과 군집 평가 지표가 개선되었으며, 전처리 방식이 군집 결과에 중요한 영향을 미칠 수 있음을 확인했습니다.

## 6. 활용 가능성

분석 결과를 바탕으로 새로운 응답자의 주간 뉴스 채널 이용 정보를 입력받아 다음 항목을 산출하는 재사용 가능한 분석 흐름을 구상했습니다.

- NNI 점수
- 전체 응답자 대비 상대적 위치(백분위)
- 군집 유형

`score_new_user()` 형태의 함수로 확장할 수 있는 구조를 검토했으며, 향후 뉴스 소비자 세분화나 미디어 이용 행태 분석에 활용할 가능성이 있습니다.

단, 이는 분석 결과를 바탕으로 구상한 활용 방안이며, 실제 서비스 배포나 운영 성과를 검증한 것은 아닙니다.

## 9. 한계 및 추가 검토 사항

- **구성 타당성:** 일부 외부 변수와의 관계가 예상과 일치하지 않아 티어 분류 및 지수 설계를 추가로 검토할 필요가 있습니다.
- **군집 분리도:** 실루엣 계수 0.5535는 유용한 세분화 가능성을 보여주지만, 군집이 명확히 분리되었다는 의미는 아닙니다.
- **분석 설정 의존성:** 채널 분류, 지수 가중치, 전처리 방법 및 군집 파라미터에 따라 결과가 달라질 수 있습니다.
- **외부 검증:** 독립적인 데이터에 대한 검증을 통해 지수와 군집의 재현성을 추가로 확인할 필요가 있습니다.
- **서비스 구현:** 신규 응답자 점수 산출은 확장 가능성을 검토한 단계이며, 실제 서비스 배포 및 운영은 수행하지 않았습니다.
